# 🌙 Margelet – Dreamcore Messenger

![chat page](main/resources/org/backrooms/backroom_messenger/Images/chatPage.png)



Margelet is a cross-platform messenger app with a surreal **dreamcore-inspired design**, offering a minimal yet mystical chatting experience. Built for both **Mac** and **Windows**, it empowers users to manage groups, channels, and personal accounts with extensive customization while staying lightweight and intuitive.

## ✨ Project Overview
Margelet is not just another messenger—it’s designed around the **dreamcore aesthetic**, blending soft visuals, liminality, and otherworldly interactions with practical features like group and channel management, file transfers, and customization.
Our goal was to create a messenger that feels **personalized**, **secure**, and **aesthetic-driven**, while still supporting advanced administrative controls.

## 🌌 Features
### 🔧 Account & Security
- Change account **password** anytime, with **Regex-based validation** to ensure strong and secure passwords.
- Logout instantly with a single click on the ❌ cross button.
- Update your **personal bio** for better self-expression.
- **Hash Passwords** for more security.

### 🗂️ File Management
- Integrated **file manager** for sending and downloading files.
- Save files directly to your system with a single click.

### 👥 Groups
- **Create public/private groups.**
- **Kick users** from groups.
- **Ban/Unban users** from groups.
- Change **group name** and **group bio** anytime.

### 📡 Channels
- **Create public/private channels.**
- **Kick users** from channels.
- Promote members to **admin** roles.
- Share **private channel links**.
- Customize **channel name** and **channel bio**.

### 🎨 Themes & Personalization
- **Dreamcore theme** as the default design language.
- Switch between different **themes**.
- Platform-specific fonts:
    - **Windows**: Uses bold surreal typefaces for a dreamlike, glitchy feel.
    - **Mac**: Uses elegant soft serif/sans fonts for a liminal atmosphere.

2. ### Cross-Platform Font Rendering
   Choosing fonts that fit the dreamcore theme but remain legible across Mac and Windows.
3. ### File Manager Integration
   Allowing seamless file upload/download across systems with their different file APIs.
4. ### User Management Complexity
   Managing advanced permissions (kick, ban, promote, etc.) while keeping controls simple and accessible.
5. ### Backend Stability Issues During CSS Integration
   During development, introducing new CSS sometimes caused unexpected backend instability or server restarts. This issue stemmed from interactions between the frontend build/watch pipeline and the backend, requiring careful dependency management and configuration tuning.
